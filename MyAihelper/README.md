# MyAihelper

This project is a simple starter agent scaffold for an AI assistant named MyAihelper.

## Features

- Minimal interactive CLI
- Basic agent loop
- Easy to extend for real AI integrations

## Run it

```bash
cd MyAihelper
npm start
```

## Verify syntax

```bash
npm run check
```

## Customize

Update the logic in `src/agent.js` to connect to a real model, add tools, or build custom workflows.
